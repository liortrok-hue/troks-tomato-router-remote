## English (en-US) — default language

**App name**
```
Troks Tomato Router Remote
```

**Short description**
```
Manage your FreshTomato router: devices, WiFi, live traffic and port forwarding
```

**Full description**
```
Troks Tomato Router Remote lets you manage a router running FreshTomato firmware from your Android phone – at home or remotely.

OVERVIEW
• Router model, firmware, uptime, CPU load and memory at a glance
• Internet (WAN) status, IP address, gateway and DNS

DEVICES
• Every connected device with name, IP, MAC, WiFi band and signal strength
• Block or unblock a device's internet access
• Reserve a static IP for any device (DHCP reservation)
• Wake-on-LAN for wired computers
• Ping a device with one tap

WIFI
• Turn each band (2.4 GHz / 5 GHz) on or off
• Change network name (SSID) and password
• See channel, security and connected clients

LIVE MONITOR
• Real-time bandwidth chart per interface (WAN, LAN, WiFi)
• Real-time traffic per device – pin one device to follow it live

MANAGE
• Internet connection: DHCP, PPPoE, static IP, DNS, MTU
• Port forwarding rules
• DMZ
• Static IP addresses
• Admin access: web UI ports, remote access, SSH, admin password

TOOLS
• Ping, traceroute and DNS lookup – run from the router itself
• Run shell commands on the router
• Reboot the router (with confirmation)

DESIGN & PRIVACY
• Material 3 design with light, dark and system themes
• English, Hebrew, Russian and Arabic
• Your router password is stored encrypted on your phone only (Android Keystore)
• For remote HTTPS access the router's certificate is pinned on first use
• No account, no ads, no analytics – the app talks only to your router

TRY IT WITHOUT A ROUTER
Tap "Try demo mode" on the login screen to explore the app with a simulated router.

REQUIREMENTS
• A router running FreshTomato firmware
• Your router's admin username and password
• For remote access: enable remote web access on the router (Administration → Admin Access)

Troks Tomato Router Remote is an independent app and is not affiliated with or endorsed by the FreshTomato project.
```
